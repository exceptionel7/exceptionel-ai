# Exceptionel AI — Landing Page

Marketing page that presents the product to the public. Converts visitors into
sign-ups.

## Deploy on Vercel
1. **Add New → Project → Import** `exceptionel7/exceptionel-ai`
2. **Root Directory** = `landing`
3. **Deploy** (no env vars needed — pure static)

## Customize
- Edit `index.html` (single file, all styles inline)
- Update the CTA links to point to your auth module URL
- Adjust the pricing, feature descriptions and branding as needed

## Connect to a custom domain
Vercel → project → **Settings → Domains** → add your domain (e.g. `exceptionel.ai`)
